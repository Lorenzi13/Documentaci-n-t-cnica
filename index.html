Box model

El box model (o modelo de caja) es el principio que define cómo el navegador representa cada elemento HTML como una caja rectangular.

Cada caja está formada por varias capas que determinan su tamaño y el espacio que ocupa.

Por ejemplo:

.caja-estandar {
  box-sizing: content-box;
  width: 300px;
  height: 100px;
  padding: 20px;
  border: 5px solid black;
  margin: 15px;
}

Elementos del box model

El modelo de caja está compuesto por estos elementos:

  • Contenido (content): es donde se muestra el texto, las imágenes u otros elementos. Sus dimensiones se controlan con las propiedades width y height.
  • Relleno (padding): es el espacio interno entre el contenido y el borde.
  • Borde (border): es la línea que rodea el contenido y el relleno. Se pueden definir su estilo, grosor y color.
  • Margen (margin): es el espacio externo que separa la caja de otros elementos.

Un ejemplo de estas propiedades:

.caja {
  width: 300px;
  padding: 20px;
  border: 5px solid black;
  margin: 15px;
}

Propiedades CSS básicas

En el ejemplo anterior:

  • La caja tiene un ancho de contenido de 300 px.
  • El relleno es de 20 px entre el contenido y el borde.
  • El borde es negro, sólido y de 5 px de grosor.
  • El margen es de 15 px alrededor de la caja.

También puedes definir cada lado por separado:

.mi-caja {
  width: 300px;
  height: 150px;

  padding-top: 10px;
  padding-right: 15px;
  padding-bottom: 10px;
  padding-left: 15px;

  border-width: 1px;
  border-style: solid;
  border-color: black;

  margin-top: 10px;
  margin-right: 15px;
  margin-bottom: 10px;
  margin-left: 15px;
  box-sizing: border-box;
}

Box sizing

La propiedad box-sizing determina cómo se calcula el tamaño de una caja. Sus valores más comunes son:

  • content-box: el ancho y alto indicados corresponden al contenido. El relleno y el borde se suman al tamaño total.
  • border-box: el ancho y alto indicados incluyen el contenido, el relleno y el borde.

Por ejemplo, con content-box, un ancho de 100 px, un relleno de 10 px por lado y un borde de 1 px por lado ocupan 122 px en total. Con border-box, el ancho total se mantiene en 100 px.

/* content-box */
.caja-estandar {
  box-sizing: content-box;
  width: 300px;
  padding: 20px;
  border: 5px solid black;
}

/* border-box */
.caja-border-box {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 5px solid black;
}

Reset universal

Una regla habitual es usar border-box para que el ancho y alto declarados incluyan el relleno y el borde. Así resulta más sencillo controlar las dimensiones de los elementos.

*,
*::before,
*::after {
  box-sizing: border-box;
}
