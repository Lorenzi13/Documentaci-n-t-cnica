# Documentación técnica de CSS

Página web introductoria sobre el modelo de caja de CSS, sus componentes y la propiedad `box-sizing`.

## Ver el proyecto

Puedes abrir `index.html` directamente en un navegador. No requiere instalar dependencias ni ejecutar un servidor.

## Contenido

- Box model: contenido, relleno, borde y margen.
- Propiedades CSS básicas para modificar cada parte de una caja.
- Diferencias entre `content-box` y `border-box`.
- Ejemplo de reset universal con `box-sizing: border-box`.
- Diseño adaptable a pantallas pequeñas.

## Archivos

- `index.html`: contenido y estructura de la documentación.
- `styles.css`: estilos, navegación adaptable y formato de los ejemplos.
